# سامانه مدیریت پادگان آموزشی سربازی

## 📋 معرفی پروژه

این سامانه یک سیستم جامع مدیریت پادگان آموزشی سربازی است که برای مدیریت کامل فرآیندهای آموزشی از روز اول تا پایان دوره طراحی شده است. این سیستم قابلیت پردازش اطلاعات خام دریافتی از تهران، مدیریت پذیرش سربازان، ثبت نامه‌ها و مدارک، و آماده‌سازی برای دوره‌های بعدی را دارد.

## 🎯 اهداف پروژه

- **مدیریت کامل فرآیند آموزشی**: از پذیرش تا پایان دوره
- **پردازش اطلاعات خام**: تبدیل داده‌های دریافتی از تهران به اطلاعات قابل استفاده
- **مدیریت سربازان**: ثبت، پیگیری و مدیریت اطلاعات کامل سربازان
- **مدیریت نامه‌ها و مدارک**: ثبت و پیگیری تمامی نامه‌ها و مدارک مربوطه
- **آماری و گزارش‌گیری**: ارائه آمار و گزارش‌های مختلف
- **پشتیبان‌گیری و بازیابی**: حفظ امنیت داده‌ها و آماده‌سازی برای دوره‌های جدید

## 🔧 نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.8+
- pip
- virtual environment
- Git

### مراحل نصب

1. **کلون کردن پروژه**
```bash
git clone [repository-url]
cd ensaniapp
```

2. **ایجاد محیط مجازی**
```bash
python -m venv venv
venv\Scripts\activate  # Windows
# یا
source venv/bin/activate  # Linux/Mac
```

3. **نصب وابستگی‌ها**
```bash
pip install -r requirements.txt
```

4. **اجرای مایگریشن‌ها**
```bash
python manage.py makemigrations
python manage.py migrate
```

5. **ایجاد کاربر ادمین**
```bash
python manage.py createsuperuser
```

6. **اجرای سرور**
```bash
python manage.py runserver
```

## 🚀 استقرار (Deployment)

### برای تولید (Production)
1. تنظیم `DEBUG = False`
2. تغییر `SECRET_KEY`
3. تنظیم `ALLOWED_HOSTS`
4. استفاده از پایگاه داده مناسب (PostgreSQL/MySQL)
5. تنظیم فایل‌های استاتیک
6. پیکربندی HTTPS

### پشتیبانی از Windows
- استفاده از `wfastcgi` برای IIS
- پیکربندی `passenger_wsgi.py`
- پشتیبانی از Windows Server
